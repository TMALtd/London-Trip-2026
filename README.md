# London Trip 2026 Parent Hub

This is a Replit-ready React + Vite site for the HELP International School London Cultural Trip 2026.

## Run locally or on Replit

1. Install packages with `npm install`
2. Start the app with `npm run dev`
3. Build a production version with `npm run build`

## Where to edit content

Most of the site content lives in:

- `/Users/benjamin.allen/Documents/London Trip 2026/src/data/tripData.js`

That file is already structured like simple tables and includes:

- trip metadata
- quick facts
- notice board items
- latest updates
- itinerary
- packing lists
- travel guidance
- safety and supervision content
- FAQs

## Important before publishing

- Replace the placeholder Google Form link.
- Add real emergency contacts.
- Add approved visa and ETA links.
- Decide whether the site will be public or private before adding any student names.
